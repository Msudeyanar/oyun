# Rock Paper Scissors Game

In this project, a classic **Rock Paper Scissors** game has been developed where you can play against the computer using Python. The game consists of 3 rounds, and in each round, 2 winners are determined. The player who wins two rounds first becomes the winner of the game.

## Game Rules

- **Rock** beats **Scissors**.
- **Scissors** beats **Paper**.
- **Paper** beats **Rock**.

The player and the computer take turns choosing Rock, Paper, or Scissors. After each selection, the winner is determined, and the game progresses.

## Project Features

- The game starts by asking the player's first and last name.
- The player and the computer make selections alternately.
- The game consists of 3 rounds, and 2 winners are determined in each round.
- At the end of the game, the total score is shown, and the player is given an option to play again.
- The computer makes random selections and competes against the player.
